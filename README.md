# Simple Calculator Tool

This project is a simple Java utility tool created for the Software Configuration Management course.

## Project Description

The tool allows users to perform basic arithmetic operations using the command line.

## Current Features

- Addition
- Subtraction

## Technologies Used

- Java
- Git
- GitHub

## Purpose

The purpose of this project is to practice version control, branching, merging, resolving conflicts, tagging releases, and documenting changes.
